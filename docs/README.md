# Documentation

User-facing documentation for GHand-ROS2 lives in the repository root and in
each package:

- [Root README](../README.md) — quick start, architecture, and build instructions.
- [中文 README](../README_CN.md) — Chinese version of the root README.
- [CONTRIBUTING.md](../CONTRIBUTING.md) — contribution guidelines and policies.
- [CHANGELOG.md](../CHANGELOG.md) — cross-package release notes.
- Package `README.md` and `CHANGELOG.rst` files under `src/<package>/`.

This directory also contains historical design notes for maintainers.
